# Тренировки

Личный трекер тренировок full body: история подходов, шаблоны циклов (А/Б),
прогресс по весам с графиками, группировка по мышцам, заметки и флажки
"до отказа" / "плохо поел" / "плохо спал".

Работает полностью в браузере, без сервера и бэкенда — все данные хранятся
в `localStorage` прямо на устройстве, ничего никуда не отправляется.

## Как включить GitHub Pages

1. Создай новый репозиторий на GitHub (или используй существующий).
2. Загрузи файл `index.html` в корень репозитория (Add file → Upload files).
3. Зайди в **Settings → Pages**.
4. В разделе **Source** выбери **Deploy from a branch**, ветку `main`, папку `/ (root)** → Save.
5. Через минуту-две страница будет доступна по адресу вида:
   `https://<твой-юзернейм>.github.io/<имя-репозитория>/`

## Важно про данные

Данные привязаны к паре "браузер + устройство", на котором открываешь страницу —
это ограничение `localStorage`, а не GitHub Pages. Если захочешь открывать
с нескольких устройств с одинаковыми данными, потребуется либо ручной
экспорт/импорт JSON, либо синхронизация через отдельное хранилище (Firebase,
Supabase и т.п.) — это уже отдельная фича, не то же самое, что просто разместить
файл на GitHub.

## Обновления

Когда я (или ты сам) поправлю `index.html` — просто перезалей файл в репозиторий
поверх старого (тем же способом, Upload files → Commit), Pages обновится
автоматически за минуту-другую.
